# 脚本处理规则

默认只处理开头第一段完整剧情，包括该段内部产品介绍、演示、效果和促销。首次产品出场不是结束点；普通反打或同一剧情换机位不是新段落。边界不明时请求用户指定结束秒数，不擅自扩到整片。

拆解忠实记录原片；转换只修改产品名称、活动、效果和包装相关短片段，保留原意、人物、剧情、动作、镜头顺序、时间和截图；迭代允许独立创作，截图须标明为原片参考。

呈现为景别、画面描述、搭配文案、对标画面截图四列。AI生成细节与连续性/转场保存在JSON。画面只记录真实可见细节，不从单帧猜测镜头运动，不编造精确时间、人物身份或器材型号。采样不等于完整逐帧观看。

画面描述用日常词和短句，先交代谁在哪里、做了什么，通常一到两句。例如「穿紫衣的女子低下头，手抬到嘴边又放下。」位置、道具和表情在有助于看懂动作时补充。服装、灯光和构图等制作细节按需写入JSON的AI生成细节。

原声识别缺漏可用真实帧中清晰可读的对话字幕补齐。台词不夹杂校对说明；场景、备注和复核项不描述字幕、水印、角标、屏幕文字。原声和画面均不可辨认的具体缺口集中放入checks。

产品资料由各安装者确认，默认模板仅有产品名称，不包含历史促销或外观资料。confirmed和currentOffers可在其授权范围内使用；visualDirection是画面设计，不是临床功效。不同产品的活动不得混用，不补造价格、赠品组成、规格、期限。用户明确允许保留原有效果口播时，将对应产品draftPolicy.retainSourceEffects设为true；这不是允许新增功效事实。

缺失问题合并后主动询问，已确认内容不反复询问。转换不得把通透换成遮瑕、速度换成持久或改变肯否疑问和因果。迭代台词采用自然对话、具体生活冲突和动作，避免说明书式独白。两种模式均不伪称已核验新生成画面。
